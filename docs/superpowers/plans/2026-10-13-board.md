# Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build board.ssutl.com: a public taste library where I drop screenshots and links (Apple Shortcut or paste), Gemini reads each one, and boards form on their own.

**Architecture:** A standalone Next.js 16 app on Vercel, modelled on the sibling Reads repo (`../reads`). Neon Postgres + pgvector holds items, boards and memberships. Vercel Blob holds images. A pipeline per item (normalise → Gemini look → crop → multimodal embed → place on boards) runs in `after()` on drop and in a 15-minute cron. Then a "grow" step forms new boards from Loose items, and a nightly cron proposes splits and merges. Pure maths (placement, grow, split/merge, crop rectangles, URL parsing) lives in small tested modules. SQL is tested for real against in-memory PGlite.

**Tech Stack:** Next.js 16.3.5, React 19.2.8, TypeScript, Tailwind v4, `@neondatabase/serverless`, pgvector, `@vercel/blob`, `sharp`, `@google/genai` (`gemini-2.5-flash`, `gemini-embedding-2`), zod 4, Vitest, `@electric-sql/pglite` (tests only).

**Spec:** `docs/superpowers/specs/2026-10-13-board-design.md`

## Global Constraints

- Next `16.3.5`, React/React DOM `19.2.8`, eslint-config-next `16.3.5`: the same versions as `../reads`.
- Embedding dimension is `1536` everywhere: the `vector(1536)` columns, `DIMENSIONS`, and the test vectors that touch the DB.
- Models: `VISION_MODEL = "gemini-2.5-flash"`, `EMBEDDING_MODEL = "gemini-embedding-2"`. `gemini-embedding-2` takes no `task_type`, so task hints go in the text part: `DOCUMENT_PREFIX = "title: none | text: "` and `QUERY_PREFIX = "task: search result | query: "`.
- Env names: `DATABASE_URL`, `BLOB_READ_WRITE_TOKEN`, `GEMINI_API_KEY`, `BOARD_PASSWORD`, `BOARD_SECRET` (≥ 32 chars), `CRON_SECRET`, `GEMINI_DAILY_CALLS` (default 500), `SEARCH_DAILY_CALLS` (default 300).
- Session cookie name `board_session`, 90 days (ported from Reads).
- Thresholds, all in `src/lib/config.ts`:
  - similarity thresholds: `JOIN_THRESHOLD 0.72`, `TIGHT_THRESHOLD 0.75`, `SPLIT_THRESHOLD 0.6`, `MERGE_THRESHOLD 0.9`
  - board sizes: `MAX_BOARDS_PER_ITEM 3`, `MIN_LOOSE_TO_GROW 12`, `MIN_BOARD_SIZE 6`, `MIN_SPLIT_BOARD 12`
  - pipeline: `MAX_ATTEMPTS 3`, stale claim 10 minutes
  - uploads and images: `MAX_UPLOAD_BYTES 15 MB`, `MAX_IMAGE_PX 2000`, `MIN_CROP_AREA 0.2`
- Accepted upload types are JPEG, PNG, WebP and GIF, detected from magic bytes. Anything else gets 415. Anything over the size cap gets 413.
- Public visibility is decided by **one** SQL fragment (`PUBLIC_MEMBERSHIPS` in `src/lib/db/public.ts`), and every public query uses it.
- Tests never call Gemini or Blob. They mock `@/lib/storage` and use `setAiForTests()`.
- Every server action calls `requireSession()` before it does anything.
- Vercel crons every 15 minutes need a Pro plan. On Hobby, set the sweep to daily in `vercel.json` (`after()` still processes every drop immediately).
- Shell note: on this machine, `cd` into a project can print an fnm error. If `node`/`npm` aren't found, prefix commands with `eval "$(fnm env --use-on-cd)" && `.

### Deviations from the spec (decided while planning; the spec is updated in Task 17)

- **Grow does not use k-means/chooseK.** Reads' `kRange` forces k ≥ 3 for anything over 12 points, which would split two real clusters into fragments that fail the size gate. Grow uses a deterministic seed-and-grow instead:
  1. Pick the point with the most neighbours at similarity ≥ `TIGHT_THRESHOLD`.
  2. Gather the points within `JOIN_THRESHOLD` of their centroid.
  3. Keep the group if it passes the size and tightness gates, then repeat.

  k-means (k = 2) is still used for split suggestions.
- `items` also gets `width` and `height` (of the shown image) for `next/image`.
- `ai_usage` is keyed by `(day, purpose)`, where purpose is `'pipeline' | 'search'`, so public searches can't eat the pipeline's daily calls.
- The spec's Look step says `crop: {x,y,w,h}`. The real format is `box: [ymin, xmin, ymax, xmax]` on a 0–1000 scale, as the spec's Failure paragraph says.

## Review Focus

1. **The same screenshot shared twice at once** (double tap in the share sheet). Expect exactly one item, with the second request returning `duplicate: true`. Pinned in Task 10 ("concurrent duplicate drops make one item").
2. **An item whose only board is hidden or deleted, or a board whose cover item is deleted.**
   - The item disappears from every public page.
   - The home page never shows a broken cover; the cover falls back to the newest public item.

   Pinned in Task 7 (cover reassignment, empty board deleted) and Task 12 (hidden board hides its items).
3. **Gemini returns malformed JSON, a nonsense box or an empty caption.** Expect the item to fail cleanly, get retried, and never stay stuck in `processing`. A 429 rate limit or a spent daily cap defers the item without using an attempt. Pinned in Task 8.
4. **A function times out mid-process,** leaving an item in `processing`. Expect it to be reclaimed after 10 minutes. Pinned in Task 7 ("stale processing claim is reclaimed").
5. **Odd links in the share sheet:** text with words around the URL, a relative `og:image`, or a redirect to a private address. Expect the first http(s) URL to be used, the relative image to resolve against the page, and the private hop to be refused. Pinned in Task 5.

`src/lib/db/client.ts`:

```ts
import "server-only";
import { neon } from "@neondatabase/serverless";

export type Statement = { text: string; params?: unknown[] };

/** The only way code talks to Postgres. Neon in production, PGlite in tests (see testing.ts). */
export interface Db {
  query<T = Record<string, unknown>>(text: string, params?: unknown[]): Promise<T[]>;
  /** Runs the statements in one transaction: all or nothing. */
  transaction(statements: Statement[]): Promise<void>;
}

let current: Db | null = null;

export function db(): Db {
  if (!current) {
    const url = process.env.DATABASE_URL;
    if (!url) throw new Error("DATABASE_URL is not set.");
    const sql = neon(url);
    current = {
      query: async <T,>(text: string, params: unknown[] = []) => (await sql.query(text, params)) as T[],
      transaction: async (statements) => {
        await sql.transaction(statements.map((s) => sql.query(s.text, s.params ?? [])));
      },
    };
  }
  return current;
}

export function setDb(d: Db | null): void {
  current = d;
}
```

`src/lib/db/testing.ts`:

```ts
import { readdirSync, readFileSync } from "node:fs";
import path from "node:path";
import { PGlite } from "@electric-sql/pglite";
import { vector } from "@electric-sql/pglite/vector";
import { afterAll, beforeAll, beforeEach } from "vitest";
import { setDb, type Db } from "./client";

const TABLES = "board_items, suggestions, boards, items, ai_usage, settings";

/** One in-memory Postgres (with pgvector) per test file, emptied before every test. */
export function useTestDb(): void {
  let pg: PGlite;
  beforeAll(async () => {
    pg = new PGlite({ extensions: { vector } });
    const dir = path.join(process.cwd(), "db", "migrations");
    for (const file of readdirSync(dir).filter((f) => f.endsWith(".sql")).sort()) {
      await pg.exec(readFileSync(path.join(dir, file), "utf8"));
    }
    const wrapped: Db = {
      query: async <T,>(text: string, params: unknown[] = []) => (await pg.query<T>(text, params)).rows,
      transaction: async (statements) => {
        await pg.transaction(async (tx) => {
          for (const s of statements) await tx.query(s.text, s.params ?? []);
        });
      },
    };
    setDb(wrapped);
  });
  beforeEach(async () => {
    await pg.exec(`truncate ${TABLES} cascade`);
  });
  afterAll(async () => {
    setDb(null);
    await pg.close();
  });
}
```

```ts
import { normalize } from "./math";

/** The unit-length mean direction of the vectors: a board's "average look". */
export function centroidOf(vectors: number[][]): number[] {
  if (vectors.length === 0) throw new Error("centroidOf needs at least one vector.");
  const sum = new Array<number>(vectors[0].length).fill(0);
  for (const v of vectors) for (let d = 0; d < v.length; d++) sum[d] += v[d];
  return normalize(sum);
}
```

```ts
import { JOIN_THRESHOLD, MAX_BOARDS_PER_ITEM } from "@/lib/config";
import { dot } from "@/lib/vectors/math";

export type Placement = { boardId: string; similarity: number };

/**
 * The boards an item joins: every one at least `threshold` similar, best first, `max` at most.
 * Callers pass only boards the item may join (not hidden, not excluded, not already pinned).
 */
export function placeItem(
  embedding: number[],
  boards: { id: string; centroid: number[] }[],
  { threshold = JOIN_THRESHOLD, max = MAX_BOARDS_PER_ITEM }: { threshold?: number; max?: number } = {},
): Placement[] {
  if (max <= 0) return [];
  return boards
    .map((b) => ({ boardId: b.id, similarity: dot(embedding, b.centroid) }))
    .filter((p) => p.similarity >= threshold)
    .sort((a, b) => b.similarity - a.similarity)
    .slice(0, max);
}
```

```ts
import { JOIN_THRESHOLD, MIN_BOARD_SIZE, MIN_LOOSE_TO_GROW, TIGHT_THRESHOLD } from "@/lib/config";
import { centroidOf } from "@/lib/vectors/centroid";
import { dot } from "@/lib/vectors/math";

export type Point = { id: string; embedding: number[] };
export type NewBoard = { itemIds: string[]; centroid: number[]; coverId: string; similarities: Record<string, number> };
export type GrowOptions = { minLoose: number; minSize: number; tight: number; join: number };

const DEFAULTS: GrowOptions = { minLoose: MIN_LOOSE_TO_GROW, minSize: MIN_BOARD_SIZE, tight: TIGHT_THRESHOLD, join: JOIN_THRESHOLD };

/**
 * New boards from the Loose pile, deterministically (seed-and-grow, not k-means, so two real
 * groups are never forced into k ≥ 3 fragments):
 * 1. seed = the point with the most neighbours at ≥ tight similarity (ties: earliest);
 * 2. members = every remaining point within `join` of the seed group's centroid;
 * 3. keep it if it has ≥ minSize members averaging ≥ tight to their centroid;
 * repeat on what's left until no seed has enough neighbours.
 */
export function findNewBoards(points: Point[], options: Partial<GrowOptions> = {}): NewBoard[] {
  const o = { ...DEFAULTS, ...options };
  const n = points.length;
  if (n < o.minLoose) return [];

  const S = new Float32Array(n * n);
  for (let i = 0; i < n; i++) {
    S[i * n + i] = 1;
    for (let j = i + 1; j < n; j++) S[i * n + j] = S[j * n + i] = dot(points[i].embedding, points[j].embedding);
  }

  const remaining = new Set(points.map((_, i) => i));
  const tried = new Set<number>();
  const out: NewBoard[] = [];

  for (;;) {
    let seed = -1;
    let best = 0;
    for (const i of remaining) {
      if (tried.has(i)) continue;
      let count = 0;
      for (const j of remaining) if (S[i * n + j] >= o.tight) count++;
      if (count > best) {
        best = count;
        seed = i;
      }
    }
    if (seed < 0 || best < o.minSize) break;
    tried.add(seed);

    const core = [...remaining].filter((j) => S[seed * n + j] >= o.tight);
    const seedCentroid = centroidOf(core.map((j) => points[j].embedding));
    const members = [...remaining].filter((j) => dot(points[j].embedding, seedCentroid) >= o.join);
    if (members.length < o.minSize) continue;

    const centroid = centroidOf(members.map((j) => points[j].embedding));
    const sims = members.map((j) => dot(points[j].embedding, centroid));
    if (sims.reduce((a, b) => a + b, 0) / sims.length < o.tight) continue;

    let cover = 0;
    sims.forEach((s, k) => {
      if (s > sims[cover]) cover = k;
    });
    out.push({
      itemIds: members.map((j) => points[j].id),
      centroid,
      coverId: points[members[cover]].id,
      similarities: Object.fromEntries(members.map((j, k) => [points[j].id, sims[k]])),
    });
    for (const j of members) remaining.delete(j);
  }
  return out;
}
```

```ts
import { createHash } from "node:crypto";
import { MERGE_THRESHOLD, MIN_BOARD_SIZE, MIN_SPLIT_BOARD, SPLIT_THRESHOLD } from "@/lib/config";
import { kmeans } from "@/lib/vectors/kmeans";
import { dot } from "@/lib/vectors/math";
import type { Point } from "./grow";

export type BoardSummary = { id: string; centroid: number[]; size: number };

/** Two clearly different halves inside one board, or null. Larger group first (it keeps the board). */
export function findSplit(
  members: Point[],
  { minBoard = MIN_SPLIT_BOARD, minSize = MIN_BOARD_SIZE, threshold = SPLIT_THRESHOLD } = {},
): { groups: [string[], string[]]; similarity: number } | null {
  if (members.length < minBoard) return null;
  const { labels, centroids } = kmeans(
    members.map((m) => m.embedding),
    2,
    { seed: 1 },
  );
  const groups: [string[], string[]] = [[], []];
  labels.forEach((label, i) => groups[label].push(members[i].id));
  if (groups[0].length < minSize || groups[1].length < minSize) return null;
  const similarity = dot(centroids[0], centroids[1]);
  if (similarity >= threshold) return null;
  return { groups: groups[0].length >= groups[1].length ? groups : [groups[1], groups[0]], similarity };
}

/** Pairs of near-identical boards, most similar first; each board in one pair at most. */
export function findMerges(boards: BoardSummary[], threshold = MERGE_THRESHOLD): { keepId: string; dropId: string; similarity: number }[] {
  const pairs: { a: BoardSummary; b: BoardSummary; similarity: number }[] = [];
  for (let i = 0; i < boards.length; i++)
    for (let j = i + 1; j < boards.length; j++) {
      const similarity = dot(boards[i].centroid, boards[j].centroid);
      if (similarity >= threshold) pairs.push({ a: boards[i], b: boards[j], similarity });
    }
  pairs.sort((x, y) => y.similarity - x.similarity);
  const used = new Set<string>();
  const out: { keepId: string; dropId: string; similarity: number }[] = [];
  for (const { a, b, similarity } of pairs) {
    if (used.has(a.id) || used.has(b.id)) continue;
    used.add(a.id);
    used.add(b.id);
    const [keep, drop] = a.size > b.size || (a.size === b.size && a.id < b.id) ? [a, b] : [b, a];
    out.push({ keepId: keep.id, dropId: drop.id, similarity });
  }
  return out;
}

/** Same type and same ids (any order) → same fingerprint, so a rejected suggestion never reopens. */
export function fingerprint(type: "split" | "merge", ids: string[]): string {
  return `${type}:${createHash("sha256").update([...ids].sort().join(",")).digest("hex")}`;
}
```

```ts
import sharp from "sharp";
import { MAX_IMAGE_PX, MIN_CROP_AREA } from "@/lib/config";

/** Gemini's box convention: [ymin, xmin, ymax, xmax], each 0–1000 of the image's height/width. */
export type Box = [number, number, number, number];
export type Rect = { left: number; top: number; width: number; height: number };
export type Rendered = { bytes: Buffer; width: number; height: number };

const clamp = (n: number) => Math.min(1000, Math.max(0, n));

/** Pixel rectangle for a box, or null when the crop is missing, nonsense, tiny (< 20%) or the whole image. */
export function cropRect(box: Box | null, width: number, height: number): Rect | null {
  if (!box) return null;
  const [y0, x0, y1, x1] = box.map(clamp);
  if (y1 <= y0 || x1 <= x0) return null;
  const left = Math.round((x0 / 1000) * width);
  const top = Math.round((y0 / 1000) * height);
  const rect = { left, top, width: Math.round((x1 / 1000) * width) - left, height: Math.round((y1 / 1000) * height) - top };
  if (rect.width < 1 || rect.height < 1) return null;
  if ((rect.width * rect.height) / (width * height) < MIN_CROP_AREA) return null;
  if (rect.width === width && rect.height === height) return null;
  return rect;
}

/** Upright JPEG (EXIF rotation applied) so Gemini's box and sharp's pixels agree. */
export async function normalizeImage(input: Uint8Array): Promise<Rendered> {
  const { data, info } = await sharp(input)
    .rotate()
    .resize({ width: 3000, height: 3000, fit: "inside", withoutEnlargement: true })
    .jpeg({ quality: 90 })
    .toBuffer({ resolveWithObject: true });
  return { bytes: data, width: info.width, height: info.height };
}

const FIT = { width: MAX_IMAGE_PX, height: MAX_IMAGE_PX, fit: "inside", withoutEnlargement: true } as const;

async function render(image: sharp.Sharp): Promise<Rendered> {
  const { data, info } = await image.resize(FIT).jpeg({ quality: 85 }).toBuffer({ resolveWithObject: true });
  return { bytes: data, width: info.width, height: info.height };
}

/** The image shown publicly (cropped when there is a crop) and the uncropped one kept alongside. */
export async function renderVariants(normal: Buffer, rect: Rect | null): Promise<{ shown: Rendered; uncropped: Rendered }> {
  const uncropped = await render(sharp(normal));
  const shown = rect ? await render(sharp(normal).extract(rect)) : uncropped;
  return { shown, uncropped };
}
```

```ts
export function firstUrl(text: string): string | null {
  const match = text.match(/https?:\/\/[^\s<>"']+/i);
  return match ? match[0].replace(/[),.;:!?]+$/, "") : null;
}

const BLOCKED = ["instagram.com", "pin.it", "x.com", "twitter.com", "tiktok.com", "threads.net"];

/** Apps that hide content from servers: save a link card and ask for a screenshot instead. */
export function isBlockedSource(url: string): boolean {
  let host: string;
  try {
    host = new URL(url).hostname.toLowerCase();
  } catch {
    return false;
  }
  if (/(^|\.)pinterest\.[a-z.]+$/.test(host)) return true;
  return BLOCKED.some((d) => host === d || host.endsWith(`.${d}`));
}

/** http(s) to a public host only: no localhost, private, link-local or credentialed URLs. */
export function isSafeFetchUrl(raw: string): boolean {
  let u: URL;
  try {
    u = new URL(raw);
  } catch {
    return false;
  }
  if (u.protocol !== "http:" && u.protocol !== "https:") return false;
  if (u.username || u.password) return false;
  const host = u.hostname.toLowerCase().replace(/^\[|\]$/g, "");
  if (host === "localhost" || host.endsWith(".localhost") || host.endsWith(".local") || host.endsWith(".internal")) return false;
  if (/^\d+\.\d+\.\d+\.\d+$/.test(host)) {
    const [a, b] = host.split(".").map(Number);
    if (a === 0 || a === 10 || a === 127 || (a === 169 && b === 254) || (a === 172 && b >= 16 && b <= 31) || (a === 192 && b === 168) || (a === 100 && b >= 64 && b <= 127))
      return false;
  }
  if (host.includes(":") && (host === "::1" || host === "::" || /^f[cd]/.test(host) || host.startsWith("fe80") || host.startsWith("::ffff:"))) return false;
  return true;
}

const ATTR = /([a-zA-Z_:][-a-zA-Z0-9_:.]*)\s*=\s*(?:"([^"]*)"|'([^']*)'|([^\s"'>]+))/g;
const ENTITIES: Record<string, string> = { amp: "&", quot: '"', "#39": "'", apos: "'", lt: "<", gt: ">" };
const decode = (s: string) =>
  s.replace(/&(amp|quot|#39|apos|lt|gt);/g, (_, e: string) => ENTITIES[e]).replace(/&#(\d+);/g, (_, n: string) => String.fromCodePoint(Number(n)));

/** The page's share image (og/twitter) and title, with the image resolved against the page URL. */
export function parseMeta(html: string, baseUrl: string): { image: string | null; title: string | null } {
  const head = html.slice(0, 500_000);
  const metas: Record<string, string> = {};
  for (const tag of head.match(/<meta\b[^>]*>/gi) ?? []) {
    const attrs: Record<string, string> = {};
    for (const m of tag.matchAll(ATTR)) attrs[m[1].toLowerCase()] = decode(m[2] ?? m[3] ?? m[4] ?? "");
    const key = (attrs.property ?? attrs.name ?? "").toLowerCase();
    if (key && attrs.content && !(key in metas)) metas[key] = attrs.content;
  }
  const raw = metas["og:image:secure_url"] ?? metas["og:image"] ?? metas["og:image:url"] ?? metas["twitter:image"] ?? metas["twitter:image:src"];
  let image: string | null = null;
  if (raw) {
    try {
      const u = new URL(raw.trim(), baseUrl);
      if (u.protocol === "http:" || u.protocol === "https:") image = u.toString();
    } catch {
      image = null;
    }
  }
  const titleTag = head.match(/<title[^>]*>([^<]*)<\/title>/i)?.[1];
  const title = (metas["og:title"] ?? (titleTag ? decode(titleTag) : "")).trim().replace(/\s+/g, " ").slice(0, 200) || null;
  return { image, title };
}

type ImageType = { mime: "image/jpeg" | "image/png" | "image/gif" | "image/webp"; ext: string };

/** The real type from the first bytes; uploads' declared types are not trusted. */
export function sniffImageType(b: Uint8Array): ImageType | null {
  const ascii = (from: number, to: number) => String.fromCharCode(...b.subarray(from, to));
  if (b[0] === 0xff && b[1] === 0xd8 && b[2] === 0xff) return { mime: "image/jpeg", ext: "jpg" };
  if (b[0] === 0x89 && ascii(1, 4) === "PNG") return { mime: "image/png", ext: "png" };
  if (ascii(0, 4) === "GIF8") return { mime: "image/gif", ext: "gif" };
  if (ascii(0, 4) === "RIFF" && ascii(8, 12) === "WEBP") return { mime: "image/webp", ext: "webp" };
  return null;
}
```

```ts
import { isSafeFetchUrl } from "./url";

export class FetchError extends Error {}

const USER_AGENT = "Mozilla/5.0 (compatible; BoardBot/1.0; +https://board.ssutl.com)";

/**
 * GET with a timeout, a byte cap (enforced while streaming, not just by content-length), an
 * allowed content type, and redirects followed by hand so every hop is checked by isSafeFetchUrl.
 */
export async function fetchLimited(
  url: string,
  { maxBytes, accept, timeoutMs = 8_000, maxRedirects = 3 }: { maxBytes: number; accept: (contentType: string) => boolean; timeoutMs?: number; maxRedirects?: number },
): Promise<{ bytes: Uint8Array; contentType: string; finalUrl: string }> {
  let current = url;
  for (let hop = 0; hop <= maxRedirects; hop++) {
    if (!isSafeFetchUrl(current)) throw new FetchError(`Refusing to fetch ${current}`);
    const res = await fetch(current, { redirect: "manual", signal: AbortSignal.timeout(timeoutMs), headers: { "user-agent": USER_AGENT, accept: "*/*" } });
    if (res.status >= 300 && res.status < 400) {
      const location = res.headers.get("location");
      if (!location) throw new FetchError("Redirect without a location.");
      current = new URL(location, current).toString();
      continue;
    }
    if (!res.ok) throw new FetchError(`HTTP ${res.status}`);
    const contentType = (res.headers.get("content-type") ?? "").split(";")[0].trim().toLowerCase();
    if (!accept(contentType)) throw new FetchError(`Unexpected content type ${contentType || "(none)"}`);
    if (Number(res.headers.get("content-length") ?? 0) > maxBytes) throw new FetchError("Too large.");
    return { bytes: await readCapped(res, maxBytes), contentType, finalUrl: current };
  }
  throw new FetchError("Too many redirects.");
}

async function readCapped(res: Response, max: number): Promise<Uint8Array> {
  if (!res.body) return new Uint8Array();
  const reader = res.body.getReader();
  const chunks: Uint8Array[] = [];
  let total = 0;
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    total += value.byteLength;
    if (total > max) {
      await reader.cancel();
      throw new FetchError("Too large.");
    }
    chunks.push(value);
  }
  const out = new Uint8Array(total);
  let offset = 0;
  for (const c of chunks) {
    out.set(c, offset);
    offset += c.byteLength;
  }
  return out;
}
```

```ts
export async function embedQuery(query: string): Promise<number[]> {
  const key = query.trim().toLowerCase();

    model: EMBEDDING_MODEL,

  return vector;
}
```

```ts
/** A 1536-d unit vector along axis i, optionally tilted toward other axes. */
export function axis(i: number, tilt: Record<number, number> = {}): number[] {
  const v = new Array<number>(DIMENSIONS).fill(0);
  v[i] = 1;
  for (const [k, w] of Object.entries(tilt)) v[Number(k)] += w;
  return normalize(v);
}
```

```ts
    },
  ]);

/** Recomputes centroids and covers; a board with no members left is deleted. */
export async function recomputeBoards(boardIds: string[]): Promise<void> {
  for (const id of new Set(boardIds)) {
    const members = await db().query<{ item_id: string; embedding: string }>(
      `select bi.item_id, i.embedding::text as embedding from board_items bi join items i on i.id = bi.item_id
       where bi.board_id = $1 and not bi.excluded and i.embedding is not null`,
      [id],
    );
    if (members.length === 0) {
      await db().transaction([
        { text: REJECT_SUGGESTIONS_FOR, params: [id] },
        { text: "delete from boards where id = $1", params: [id] },
      ]);
      continue;
    }
    const vectors = members.map((m) => fromVector(m.embedding));
    const centroid = centroidOf(vectors);
    const [board] = await db().query<{ cover_item_id: string | null }>("select cover_item_id from boards where id = $1", [id]);
    if (!board) continue;
    let cover = board.cover_item_id;
    if (!members.some((m) => m.item_id === cover)) {
      let best = 0;
      vectors.forEach((v, k) => {
        if (dot(v, centroid) > dot(vectors[best], centroid)) best = k;
      });
      cover = members[best].item_id;
    }
    await db().query("update boards set centroid = $2::vector, cover_item_id = $3, updated_at = now() where id = $1", [id, toVector(centroid), cover]);
  }
}
```

```ts
  return Buffer.from(await res.arrayBuffer());
```

```ts
import "server-only";
import { embedImage, lookAt, rateLimitDelayMs } from "@/lib/ai/gemini";
import { placeItem } from "@/lib/boards/place";
import { MAX_BOARDS_PER_ITEM } from "@/lib/config";
import { boardsForPlacement, recomputeBoards, replaceAutoMemberships } from "@/lib/db/boards";
import { claimItem, markFailed, markReady, releaseClaim, saveProcessed } from "@/lib/db/items";
import { BudgetExceeded } from "@/lib/db/usage";
import { cropRect, normalizeImage, renderVariants } from "@/lib/images/crop";
import { deleteFiles, download, putImage } from "@/lib/storage";

export type ProcessOutcome = "ready" | "failed" | "deferred" | "skipped";

/** Errors that mean "try again later" rather than "this item is broken". */
const isTransient = (error: unknown) => error instanceof BudgetExceeded || rateLimitDelayMs(error) !== null;

/** Look → crop → store → embed → place. Safe to call twice: only the run that claims the item works on it. */
export async function processItem(id: string): Promise<ProcessOutcome> {
  const item = await claimItem(id);
  if (!item) return "skipped";
  try {
    if (!item.original_url) throw new Error("Item has no original image.");
    const normal = await normalizeImage(await download(item.original_url));
    const look = await lookAt(normal.bytes);
    const rect = item.use_crop ? cropRect(look.box, normal.width, normal.height) : null;
    const { shown, uncropped } = await renderVariants(normal.bytes, rect);
    const stamp = Date.now();
    const imageUrl = await putImage(`items/${id}/shown-${stamp}.jpg`, shown.bytes, "image/jpeg");
    const uncroppedUrl = shown === uncropped ? imageUrl : await putImage(`items/${id}/full-${stamp}.jpg`, uncropped.bytes, "image/jpeg");
    const embedding = await embedImage(shown.bytes, look.caption);
    await saveProcessed(id, { imageUrl, uncroppedUrl, width: shown.width, height: shown.height, caption: look.caption, tags: look.tags, embedding });
    await placeOnBoards(id, embedding);
    await markReady(id);
    const stale = [item.image_url, item.uncropped_url].filter((u): u is string => !!u && u !== imageUrl && u !== uncroppedUrl);
    if (stale.length) await deleteFiles(stale).catch((e) => console.warn("could not delete old files", e));
    return "ready";
  } catch (error) {
    if (isTransient(error)) {
      await releaseClaim(id);
      return "deferred";
    }
    console.error(`processItem ${id}`, error);
    await markFailed(id, error instanceof Error ? error.message : String(error));
    return "failed";
  }
}

/** Auto-places an item: never on hidden or excluded boards; pinned boards count toward the 3. */
export async function placeOnBoards(itemId: string, embedding: number[]): Promise<void> {
  const boards = await boardsForPlacement(itemId);
  const pinned = boards.filter((b) => b.pinned).length;
  const candidates = boards.filter((b) => !b.hidden && !b.excluded && !b.pinned);
  const placements = placeItem(embedding, candidates, { max: MAX_BOARDS_PER_ITEM - pinned });
  await replaceAutoMemberships(itemId, placements);
  await recomputeBoards([...boards.filter((b) => b.member).map((b) => b.id), ...placements.map((p) => p.boardId)]);
}
```

```ts
import "server-only";
import { nameBoard } from "@/lib/ai/gemini";
import { findMerges, findSplit, fingerprint } from "@/lib/boards/suggest";
import { MIN_SPLIT_BOARD } from "@/lib/config";
import { boardMembers, boardSummaries, createBoard, mergeBoards, moveMembers, renameBoard, setBoardDescription } from "@/lib/db/boards";
import { acquireLease, releaseLease } from "@/lib/db/settings";
import { boardsWithOpenSuggestions, getSuggestion, openSuggestion, setSuggestionStatus, suggestionExists } from "@/lib/db/suggestions";
import { centroidOf } from "@/lib/vectors/centroid";
import { isTransient } from "./process";

const LEASE = "suggest_lock";

/** Nightly: proposes splits and merges. One open suggestion per board; a rejected one never reopens. */
export async function runSuggestions(): Promise<number> {
  if (!(await acquireLease(LEASE, 10 * 60_000))) return 0;
  let opened = 0;
  try {
    const boards = (await boardSummaries()).filter((b) => !b.hidden);
    const busy = await boardsWithOpenSuggestions();

    for (const b of boards) {
      if (busy.has(b.id) || b.size < MIN_SPLIT_BOARD) continue;
      const members = await boardMembers(b.id);
      const split = findSplit(members.map((m) => ({ id: m.itemId, embedding: m.embedding })));
      if (!split) continue;
      const fp = fingerprint("split", [b.id, ...members.map((m) => m.itemId)]);
      if (await suggestionExists(fp)) continue;
      const captions = new Map(members.map((m) => [m.itemId, m.caption ?? ""]));
      const groups = [];
      for (const itemIds of split.groups) {
        const named = await nameBoard(itemIds.map((id) => captions.get(id) ?? "").filter(Boolean));
        groups.push({ itemIds, ...named });
      }
      if (await openSuggestion({ type: "split", payload: { boardId: b.id, groups } }, fp)) {
        opened++;
        busy.add(b.id);
      }
    }

    for (const m of findMerges(boards.filter((b) => !busy.has(b.id)))) {
      const ids = [m.keepId, m.dropId, ...(await boardMembers(m.keepId)).map((x) => x.itemId), ...(await boardMembers(m.dropId)).map((x) => x.itemId)];
      if (await openSuggestion({ type: "merge", payload: m }, fingerprint("merge", ids))) opened++;
    }
    return opened;
  } catch (error) {
    if (isTransient(error)) return opened;
    throw error;
  } finally {
    await releaseLease(LEASE);
  }
}

export async function acceptSuggestion(id: string): Promise<void> {
  const s = await getSuggestion(id);
  if (!s || s.status !== "open") throw new Error("That suggestion is no longer open.");
  if (s.type === "merge") {
    await mergeBoards(s.payload.keepId, s.payload.dropId);
  } else {
    const { boardId, groups } = s.payload;
    const [keep, move] = groups;
    const members = await boardMembers(boardId);
    const moving = members.filter((m) => move.itemIds.includes(m.itemId));
    if (moving.length === 0) throw new Error("Nothing left to split off.");
    await renameBoard(boardId, keep.name);
    await setBoardDescription(boardId, keep.description);
    const created = await createBoard({
      name: move.name,
      description: move.description,
      centroid: centroidOf(moving.map((m) => m.embedding)),
      coverItemId: moving[0].itemId,
      members: [],
    });
    await moveMembers(boardId, created.id, moving.map((m) => m.itemId));
  }
  await setSuggestionStatus(id, "accepted");
}

export async function rejectSuggestion(id: string): Promise<void> {
  await setSuggestionStatus(id, "rejected");
}
```

```ts
export function bearer(req: Request): string | null {
  const match = req.headers.get("authorization")?.match(/^Bearer\s+(.+)$/i);
  return match ? match[1].trim() : null;
}

function cookie(req: Request, name: string): string | undefined {
  for (const part of (req.headers.get("cookie") ?? "").split(";")) {
    const [k, ...v] = part.trim().split("=");
    if (k === name) return decodeURIComponent(v.join("="));
  }
  return undefined;
}

/** The Apple Shortcut's Bearer key, or the edit side's session cookie (desktop paste). */
export async function dropAuthorized(req: Request): Promise<boolean> {
  const token = bearer(req);
  if (token) return verifyDropKey(token);
  return verifySession(cookie(req, SESSION_COOKIE), sessionSecret());
}

export function cronAuthorized(req: Request): boolean {
  const secret = process.env.CRON_SECRET;
```

```ts
import "server-only";
import { createHash } from "node:crypto";
import { MAX_PAGE_BYTES, MAX_UPLOAD_BYTES } from "@/lib/config";
import { findIdByHash, insertImageItem, insertLinkItem } from "@/lib/db/items";
import { putImage } from "@/lib/storage";
import { fetchLimited } from "./fetch";
import { firstUrl, isBlockedSource, isSafeFetchUrl, parseMeta, sniffImageType } from "./url";

export type DropBody = { id?: string; kind?: "image" | "link"; duplicate?: boolean; blocked?: boolean; error?: string };
export type DropResult = { status: number; body: DropBody; processId?: string };

/** Accepts `file`, `input` (the Shortcut's one field) or `url`: a File is an image, text is searched for a link. */
export async function handleDrop(form: FormData): Promise<DropResult> {
  const value = form.get("file") ?? form.get("input") ?? form.get("url");
  if (value instanceof File) {
    if (value.size > MAX_UPLOAD_BYTES) return { status: 413, body: { error: "That file is over 15 MB." } };
    return dropImage(new Uint8Array(await value.arrayBuffer()));
  }
  if (typeof value === "string") {
    const url = firstUrl(value);
    if (url) return dropUrl(url);
  }
  return { status: 400, body: { error: "Send an image or a link." } };
}

async function dropImage(bytes: Uint8Array, { sourceUrl = null, title = null }: { sourceUrl?: string | null; title?: string | null } = {}): Promise<DropResult> {
  if (bytes.byteLength > MAX_UPLOAD_BYTES) return { status: 413, body: { error: "That file is over 15 MB." } };
  const type = sniffImageType(bytes);
  if (!type) return { status: 415, body: { error: "Only JPEG, PNG, WebP or GIF images." } };
  const hash = createHash("sha256").update(bytes).digest("hex");
  const existing = await findIdByHash(hash);
  if (existing) return { status: 200, body: { id: existing, kind: "image", duplicate: true } };
  const originalUrl = await putImage(`originals/${hash}.${type.ext}`, bytes, type.mime);
  const { id, created } = await insertImageItem({ contentHash: hash, originalUrl, sourceUrl, title });
  return created ? { status: 201, body: { id, kind: "image" }, processId: id } : { status: 200, body: { id, kind: "image", duplicate: true } };
}

const isHtml = (t: string) => t === "text/html" || t === "application/xhtml+xml";
const isImage = (t: string) => t.startsWith("image/");

async function dropUrl(url: string): Promise<DropResult> {
  if (!isSafeFetchUrl(url)) return { status: 400, body: { error: "That link can't be fetched." } };
  if (isBlockedSource(url)) {
    const id = await insertLinkItem({ sourceUrl: url, title: null, blocked: true });
    return { status: 201, body: { id, kind: "link", blocked: true } };
  }
  let title: string | null = null;
  try {
    const page = await fetchLimited(url, { maxBytes: Math.max(MAX_PAGE_BYTES, MAX_UPLOAD_BYTES), accept: (t) => isHtml(t) || isImage(t) });
    if (isImage(page.contentType)) {
      const direct = await dropImage(page.bytes, { sourceUrl: url });
      if (direct.status < 400) return direct;
    } else {
      const meta = parseMeta(new TextDecoder().decode(page.bytes.subarray(0, MAX_PAGE_BYTES)), page.finalUrl);
      title = meta.title;
      if (meta.image) {
        const image = await fetchLimited(meta.image, { maxBytes: MAX_UPLOAD_BYTES, accept: isImage });
        const result = await dropImage(image.bytes, { sourceUrl: url, title });
        if (result.status < 400) return result;
      }
    }
  } catch (error) {
    console.warn(`drop: could not read ${url}`, error);
  }
  const id = await insertLinkItem({ sourceUrl: url, title, blocked: false });
  return { status: 201, body: { id, kind: "link" } };
}
```

```ts
export async function POST(req: Request) {

  if (Number(req.headers.get("content-length") ?? 0) > MAX_UPLOAD_BYTES + 1024 * 1024)

      await processItem(id);
      await growBoards();
    });
  return Response.json(result.body, { status: result.status });
}
```

```ts
import "server-only";
import { hasTime } from "@/lib/ai/budget";
import { claimableIds } from "@/lib/db/items";
import { growBoards } from "./grow";
import { processItem, type ProcessOutcome } from "./process";

/** Catches up on anything the drop's after() missed or that failed with attempts left. */
export async function sweep(until: number, now: () => number = Date.now): Promise<Record<ProcessOutcome, number> & { boards: number }> {
  const counts = { ready: 0, failed: 0, deferred: 0, skipped: 0, boards: 0 };
  for (const id of await claimableIds(100)) {
    if (!hasTime(now(), until)) break;
    const outcome = await processItem(id);
    counts[outcome]++;
    if (outcome === "deferred") break; // budget spent or rate-limited: the rest would defer too
  }
  if (hasTime(now(), until)) counts.boards = await growBoards();
  return counts;
}
```

```ts
import "server-only";
import type { Tags } from "@/lib/ai/look";
import { db } from "./client";
import { toVector } from "./vector";

/**
 * THE visibility rule: an item is public through a membership that isn't excluded, on a board
 * that isn't hidden, when the item is a ready, unhidden image. Every public read goes through this.
 */
export const PUBLIC_MEMBERSHIPS = `select bi.item_id, bi.board_id from board_items bi
  join items i on i.id = bi.item_id
  join boards b on b.id = bi.board_id
  where not bi.excluded and not b.hidden and i.status = 'ready' and i.kind = 'image' and not i.hidden and i.image_url is not null`;

export type PublicItem = { id: string; image_url: string; width: number; height: number; caption: string | null };
export type PublicItemDetail = PublicItem & { title: string | null; source_url: string | null; tags: Partial<Tags> };
export type BoardCardData = { id: string; slug: string; name: string; count: number; images: string[] };
export type PublicBoard = { id: string; slug: string; name: string; description: string; coverUrl: string | null };

const ITEM = "i.id, i.image_url, i.width, i.height, i.caption";
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

export async function listPublicBoards(): Promise<BoardCardData[]> {
  const rows = await db().query<{ id: string; slug: string; name: string; count: number; cover: string | null; recent: string[] | null }>(
    `with pm as (${PUBLIC_MEMBERSHIPS})
     select b.id, b.slug, b.name, count(*)::int as count,
       (select i2.image_url from pm p2 join items i2 on i2.id = p2.item_id where p2.board_id = b.id and p2.item_id = b.cover_item_id) as cover,
       (select array_agg(x.image_url) from (
          select i3.image_url from pm p3 join items i3 on i3.id = p3.item_id
          where p3.board_id = b.id and i3.id is distinct from b.cover_item_id order by i3.created_at desc limit 3) x) as recent,
       max(i.created_at) as latest
     from boards b join pm on pm.board_id = b.id join items i on i.id = pm.item_id
     group by b.id order by latest desc`,
  );
  return rows.map((r) => ({
    id: r.id,
    slug: r.slug,
    name: r.name,
    count: r.count,
    images: [r.cover, ...(r.recent ?? [])].filter((u): u is string => !!u).slice(0, 3),
  }));
}

export async function getPublicBoard(slug: string): Promise<PublicBoard | null> {
  const [row] = await db().query<PublicBoard>(
    `with pm as (${PUBLIC_MEMBERSHIPS})
     select b.id, b.slug, b.name, b.description,
       coalesce(
         (select i.image_url from pm join items i on i.id = pm.item_id where pm.board_id = b.id and pm.item_id = b.cover_item_id),
         (select i.image_url from pm join items i on i.id = pm.item_id where pm.board_id = b.id order by i.created_at desc limit 1)
       ) as "coverUrl"
     from boards b where b.slug = $1 and exists (select 1 from pm where pm.board_id = b.id)`,
    [slug],
  );
  return row ?? null;
}

export async function boardItems(boardId: string, colour: string | null = null): Promise<PublicItem[]> {
  return db().query<PublicItem>(
    `with pm as (${PUBLIC_MEMBERSHIPS})
     select ${ITEM} from pm join items i on i.id = pm.item_id
     where pm.board_id = $1 and ($2::text is null or i.tags->'palette' ? $2::text)
     order by i.created_at desc`,
    [boardId, colour],
  );
}

export async function boardPalette(boardId: string): Promise<{ colour: string; count: number }[]> {
  return db().query<{ colour: string; count: number }>(
    `with pm as (${PUBLIC_MEMBERSHIPS})
     select c as colour, count(*)::int as count
     from pm join items i on i.id = pm.item_id, jsonb_array_elements_text(coalesce(i.tags->'palette', '[]'::jsonb)) as c
     where pm.board_id = $1 group by c order by count desc, c`,
    [boardId],
  );
}

export async function getPublicItem(id: string): Promise<PublicItemDetail | null> {
  if (!UUID.test(id)) return null;
  const [row] = await db().query<PublicItemDetail>(
    `with pm as (${PUBLIC_MEMBERSHIPS})
     select ${ITEM}, i.title, i.source_url, i.tags from items i
     where i.id = $1 and exists (select 1 from pm where pm.item_id = i.id)`,
    [id],
  );
  return row ?? null;
}

export async function boardsForItem(id: string): Promise<{ slug: string; name: string }[]> {
  if (!UUID.test(id)) return [];
  return db().query<{ slug: string; name: string }>(
    `with pm as (${PUBLIC_MEMBERSHIPS})
     select b.slug, b.name from pm join boards b on b.id = pm.board_id where pm.item_id = $1 order by b.name`,
    [id],
  );
}

export async function similarPublicItems(id: string, limit = 12): Promise<PublicItem[]> {
  if (!UUID.test(id)) return [];
  return db().query<PublicItem>(
    `with pm as (${PUBLIC_MEMBERSHIPS}), pub as (select distinct item_id from pm)
     select ${ITEM} from items i join pub on pub.item_id = i.id
     where i.id <> $1 and i.embedding is not null
     order by i.embedding <=> (select embedding from items where id = $1) limit $2`,
    [id, limit],
  );
}

export async function searchPublic(vector: number[]): Promise<{ items: PublicItem[]; boards: { slug: string; name: string }[] }> {
  const v = toVector(vector);
  const [items, boards] = await Promise.all([
    db().query<PublicItem>(
      `with pm as (${PUBLIC_MEMBERSHIPS}), pub as (select distinct item_id from pm)
       select ${ITEM} from items i join pub on pub.item_id = i.id where i.embedding is not null
       order by i.embedding <=> $1::vector limit 48`,
      [v],
    ),
    db().query<{ slug: string; name: string }>(
      `with pm as (${PUBLIC_MEMBERSHIPS})
       select b.slug, b.name from boards b where exists (select 1 from pm where pm.board_id = b.id)
       order by b.centroid <=> $1::vector limit 3`,
      [v],
    ),
  ]);
  return { items, boards };
}
```

```tsx
"use client";

import { useEffect, useRef } from "react";

/** GET /search?q=…; "/" focuses it from anywhere on the page. */
export function SearchBox({ defaultValue = "" }: { defaultValue?: string }) {
  const ref = useRef<HTMLInputElement>(null);
  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      const typing = e.target instanceof HTMLInputElement || e.target instanceof HTMLTextAreaElement;
      if (e.key === "/" && !typing) {
        e.preventDefault();
        ref.current?.focus();
      }
    };
    window.addEventListener("keydown", onKey);
    return () => window.removeEventListener("keydown", onKey);
  }, []);
  return (
    <form action="/search" className="w-full max-w-xs">
      <input
        ref={ref}
        name="q"
        defaultValue={defaultValue}
        maxLength={200}
        placeholder="Search by feel…  /"
        className="w-full rounded-md border border-edge bg-card px-3 py-1.5 text-sm outline-none focus:border-ink"
      />
    </form>
  );
}
```

```ts
import { NextResponse, type NextRequest } from "next/server";
import { SESSION_COOKIE, sessionSecret, verifySession } from "@/lib/auth/session";

/**
 * A browser opening the page, rather than the router fetching part of it. Next strips the RSC
 * flight headers before the proxy runs, so Sec-Fetch-Dest is all that's left: a shutter, not
 * the lock. The lock is hasSession() in every edit page and requireSession() in every action.
 */
function isDocumentRequest(req: NextRequest): boolean {
  const dest = req.headers.get("sec-fetch-dest");
  return (dest === null || dest === "document") && !req.nextUrl.pathname.endsWith(".rsc");
}

export async function proxy(req: NextRequest) {
  if (await verifySession(req.cookies.get(SESSION_COOKIE)?.value, sessionSecret())) return NextResponse.next();
  // Server actions (signing in is one) POST to the page path; each checks the session itself.
  if (req.method === "POST" && (req.headers.has("next-action") || req.headers.get("content-type")?.startsWith("multipart/form-data")))
    return NextResponse.next();
  return isDocumentRequest(req) ? NextResponse.next() : NextResponse.json({ error: "Not logged in." }, { status: 401 });
}

export const config = {
  // /api/drop and the cron routes check their own credentials. Must stay a literal: Next reads it statically.
  matcher: ["/edit", "/edit/:path*"],
};
```

```tsx
"use client";

import { useRouter } from "next/navigation";
import { useCallback, useEffect, useState } from "react";

type Entry = { label: string; message: string; ok: boolean };

function describe(status: number, data: { duplicate?: boolean; blocked?: boolean; kind?: string; error?: string }): Entry["message"] {
  if (status >= 400) return data.error ?? `Failed (${status})`;
  if (data.duplicate) return "Already saved";
  if (data.blocked) return "Saved as a link. Screenshot it instead.";
  if (data.kind === "link") return "No image found. Saved as a link card.";
  return "Saved, sorting…";
}

/** ⌘V anywhere on the page, drag files in, or paste a link into the box. Posts to /api/drop with the session cookie. */
export function DropZone() {
  const router = useRouter();
  const [log, setLog] = useState<Entry[]>([]);
  const [url, setUrl] = useState("");
  const [over, setOver] = useState(false);

  const send = useCallback(
    async (label: string, field: "file" | "url", value: Blob | string) => {
      const body = new FormData();
      body.append(field, value);
      const res = await fetch("/api/drop", { method: "POST", body });
      const data = await res.json().catch(() => ({}));
      setLog((l) => [{ label, message: describe(res.status, data), ok: res.ok }, ...l].slice(0, 20));
      router.refresh();
    },
    [router],
  );

  useEffect(() => {
    const onPaste = (e: ClipboardEvent) => {
      const files = [...(e.clipboardData?.files ?? [])];
      if (files.length) {
        e.preventDefault();
        files.forEach((f) => send(f.name || "Pasted image", "file", f));
        return;
      }
      const text = e.clipboardData?.getData("text")?.trim() ?? "";
      if (/^https?:\/\//i.test(text) && !(e.target instanceof HTMLInputElement)) {
        e.preventDefault();
        send(text, "url", text);
      }
    };
    window.addEventListener("paste", onPaste);
    return () => window.removeEventListener("paste", onPaste);
  }, [send]);

  return (
    <section className="mb-10">
      <div
        onDragOver={(e) => {
          e.preventDefault();
          setOver(true);
        }}
        onDragLeave={() => setOver(false)}
        onDrop={(e) => {
          e.preventDefault();
          setOver(false);
          [...e.dataTransfer.files].forEach((f) => send(f.name, "file", f));
        }}
        className={`flex min-h-40 flex-col items-center justify-center gap-3 rounded-lg border-2 border-dashed p-6 text-center text-sm ${over ? "border-ink bg-card" : "border-edge text-muted"}`}
      >
        <p>Paste (⌘V) a screenshot or link anywhere on this page, or drop images here.</p>
        <form
          className="flex w-full max-w-md gap-2"
          onSubmit={(e) => {
            e.preventDefault();
            if (url.trim()) send(url.trim(), "url", url.trim());
            setUrl("");
          }}
        >
          <input value={url} onChange={(e) => setUrl(e.target.value)} placeholder="https://…" className="flex-1 rounded-md border border-edge bg-card px-3 py-1.5 outline-none focus:border-ink" />
          <button className="rounded-md bg-ink px-3 py-1.5 text-paper">Add</button>
        </form>
      </div>
      {log.length > 0 && (
        <ul className="mt-3 space-y-1 text-sm">
          {log.map((entry, i) => (
            <li key={i} className={entry.ok ? "" : "text-red-700"}>
              <span className="text-muted">{entry.label.slice(0, 60)}</span> {entry.message}
            </li>
          ))}
        </ul>
      )}
    </section>
  );
}
```

```ts
// npm run db:similarity: distribution of nearest-neighbour and board similarities on real items.
import { db } from "@/lib/db/client";
import { fromVector } from "@/lib/db/vector";
import { dot } from "@/lib/vectors/math";

const items = (await db().query<{ id: string; caption: string | null; embedding: string }>(
  "select id, caption, embedding::text as embedding from items where status = 'ready' and embedding is not null",
)).map((r) => ({ ...r, v: fromVector(r.embedding) }));
const boards = (await db().query<{ name: string; centroid: string }>("select name, centroid::text as centroid from boards")).map((b) => ({ ...b, v: fromVector(b.centroid) }));

const pct = (xs: number[], p: number) => xs.sort((a, b) => a - b)[Math.floor((xs.length - 1) * p)]?.toFixed(3);
const nearest = items.map((a) => Math.max(...items.filter((b) => b !== a).map((b) => dot(a.v, b.v))));
console.log(`items: ${items.length}  nearest-neighbour similarity p10/p50/p90: ${pct(nearest, 0.1)} / ${pct(nearest, 0.5)} / ${pct(nearest, 0.9)}`);
for (const b of boards) {
  const sims = items.map((i) => dot(i.v, b.v));
  console.log(`${b.name.padEnd(28)} members≥0.72: ${sims.filter((s) => s >= 0.72).length}  best: ${Math.max(...sims).toFixed(3)}`);
}
```
